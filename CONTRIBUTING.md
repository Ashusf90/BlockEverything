# Overview

This is open source, (MIT liscense). To contribute, be sure to follow the rules. 

# The rules

- Don't use AI to write code for this site, if code looks vibed, then it may be rejected.
- Test code before pull request.
- Include information in pull requests.

# Include information

Explain impacts of your code, why you are doing this pull request, and what consequences it has on the codebase.

Information like what: chrome version you used to test, what os you are using, and important notes should be included.
